# FloatingTodoTimer (macOS)

최대 5개의 우선순위 할 일(Todo)과 태스크별 카운트다운 타이머·누적 시간 추적을 결합한 초경량 **macOS 항상 위(Always-on-Top) 플로팅 위젯 앱**입니다.

---

## 무엇을 하는 앱인가요?

작업 중 화면을 가리지 않고 가장 중요한 할 일(최대 5개)에만 집중할 수 있도록 만든 macOS 메뉴바/플로팅 위젯입니다.

### 핵심 특징
1. **방해 없는 항상 위 플로팅 창 (`NSPanel`)**
   - 모든 일반 창 및 전체화면(Fullscreen) 앱, 모든 가상 데스크톱(Spaces) 위에 항상 떠 있습니다.
   - 일반 버튼(재생/일시정지, 완료 체크, 순서 변경, 마크다운 복사)을 눌러도 현재 작업 중인 앱의 키보드 포커스를 빼앗지 않으며, 텍스트를 입력할 때만 키 포커스를 가져옵니다.
   - Dock 및 `Cmd+Tab` 앱 스위처에 나타나지 않는 백그라운드 에이전트(`LSUIElement = YES`)로 동작합니다.

2. **컴팩트 모드 ↔ 수정(확장) 모드 부드러운 전환 (`300px` 고정 가로폭)**
   - **컴팩트 모드 (`300 x 44 px`)**: 기본 상태. 현재 타이머가 실행 중인 태스크(없을 경우 최우선 미완료 태스크)의 `[#우선순위] [할 일 제목] [남은 시간] [▶/⏸]`만 간결하게 표시합니다.
   - **수정/확장 모드 (`300 x 280 px`)**: 위젯 위에 마우스를 **0.5초 이상** 올려두면 아래로 부드럽게 펼쳐지며, 마우스를 치우면 즉시 컴팩트 모드로 돌아갑니다.
   - 글로벌 단축키 **`Option + Space` (`⌥Space`)** 또는 우측 상단 핀(`📌`) 버튼으로 확장 상태를 고정(Pin)할 수 있습니다.

3. **최대 5개 할 일 관리 & 간편한 인라인 수정**
   - 동시에 최대 **5개**까지만 등록할 수 있어 핵심 우선순위에 집중하도록 돕습니다.
   - 할 일 제목을 **더블클릭** 또는 **우클릭**하면 즉시 제목을 수정할 수 있습니다 (`Enter` 또는 `✓` 클릭 시 저장).
   - 각 항목의 `▲`/`▼` 버튼으로 우선순위(1~5순위)를 즉시 변경할 수 있습니다.

4. **기본 1시간(`01:00:00`) 카운트다운 타이머 & 누적 시간 추적**
   - **단일 활성 타이머**: 한 번에 하나의 태스크 타이머만 실행됩니다. 다른 태스크를 시작(`▶`)하면 기존 타이머는 자동으로 일시정지(`⏸`)됩니다.
   - **시간 직접 설정**: 수정 화면에서 각 태스크의 남은 시간 배지(예: `01:00:00`)를 클릭하면 `-10m`, `-5m`, `+5m`, `+10m`, `60m` 버튼 또는 직접 분(Minute) 입력으로 타이머 시간을 자유롭게 변경할 수 있습니다.
   - **누적 시간 보존**: 타이머 시간을 변경하거나 여러 세션을 반복 실행해도 실제 사용한 **누적 시간**은 각 할 일 하단(`누적 12m 30s`)과 상단 헤더(`· 누적 1h 15m`)에 정확히 기록됩니다.
   - **슬립 오차 방지**: 시스템 시각 차이(`Date().timeIntervalSince(lastResumedAt)`) 기반으로 계산하여 맥북 잠자기/백그라운드 상태에서도 시간이 밀리지 않습니다.

5. **일자별 자동 저장 & 미완료 태스크 이월 + Obsidian 마크다운 복사**
   - `~/Library/Application Support/FloatingTodoTimer/YYYY-MM-DD.json`에 실시간으로 자동 저장됩니다.
   - 날짜가 바뀌면 이전 날짜의 **미완료 태스크와 누적 시간**이 자동으로 오늘 파일로 이월됩니다.
   - 상단 **`Copy MD`** 버튼 클릭 시 클립보드에 Obsidian 호환 마크다운 형식으로 복사됩니다:
     ```markdown
     - [x] Task Title 1 (1h 15m)
     - [ ] Task Title 2 (0h 32m)
     ```

## 요구 사항

- **macOS 14.0 (Sonoma) 이상**
- **Swift 5.9 이상** (Xcode 또는 Command Line Tools)

## 빌드 및 실행 방법

### 1. `.app` 번들 빌드 후 실행 (권장)

프로젝트 루트에서 제공되는 스크립트를 실행하면 `build/FloatingTodoTimer.app` 번들이 생성됩니다.

```bash
# 1) .app 번들 빌드 (기본: release, 빠른 디버그 빌드는 ./scripts/build_app.sh debug)
./scripts/build_app.sh

# 2) 앱 실행
open ./build/FloatingTodoTimer.app
```

이미 실행 중인 앱을 재시작할 때:
```bash
killall FloatingTodoTimer 2>/dev/null; open ./build/FloatingTodoTimer.app
```

### 2. 메뉴바(Menu Bar) 및 단축키 사용법

- **위치 이동**: 위젯의 빈 배경 영역을 드래그하여 원하는 위치에 놓으면 좌표가 자동 저장됩니다.
- **확장 화면 고정/해제**: `Option + Space` (`⌥Space`) 또는 확장 화면 우측 상단 핀(`📌`) 아이콘 클릭.
- **메뉴바 아이콘(⏱)**: 화면 우측 상단 메뉴바의 타이머 아이콘을 클릭하면 **창 위치 초기화(Reset Window Position)**, **Obsidian 마크다운 복사**, **앱 종료(Quit)**를 실행할 수 있습니다.

### 3. 자체 기능 검증 테스트 실행

```bash
./build/FloatingTodoTimer.app/Contents/MacOS/FloatingTodoTimer --self-test
```
